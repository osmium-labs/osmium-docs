# Osmium documentation

Guides for running Osmium.

* [Masternode and supernode setup](masternode-setup.md): set up a node on an Ubuntu server, register
  it from your wallet, keep it running, and host nodes for other people.
* [Governance: proposals, superblocks and voting](governance.md): how the monthly budget works,
  how to submit a proposal, and how masternode and supernode owners vote.

Osmium Core downloads are on the
[releases page](https://github.com/osmium-labs/osmium/releases). For questions, join the
[Osmium Discord](https://discord.gg/DM4W2E9Rfa).
